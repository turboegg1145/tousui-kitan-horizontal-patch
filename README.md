# 《灯穂奇譚》简体中文汉化版 - 横版文字补丁

本项目为同人视觉小说《灯穂奇譚》（Tousui Kitan / 水鏡社 AOD 引擎）简体中文汉化版的**横版文字排版补丁**与**全自动生成工具**。

---

## 📖 背景与制作动机

《灯穂奇譚》（水鏡，2005）原本为传统的日式纵书（竖排）视觉小说。汉化组在 2011 年发布了汉化版（`tosui_cn.exe`），但依然保留了原本的竖排阅读格式。

在现代 PC 宽屏显示器下，竖排阅读容易导致：
1. **视觉疲劳与阅读习惯冲突**：中文习惯自左向右横向阅读，竖排在宽屏下视线跳跃幅度大。
2. **标点符号错位畸变**：旧汉化补丁中的竖排标点变换机制（引号 90 度旋转、句号右上角浮动偏移）容易引起字符显示异常。

本补丁通过对 AOD 引擎底层排版与渲染流水线的二进制逆向分析，**完整切换为现代横向排版，并修复了全部标点符号的旋转与对齐问题**。

---

## ✨ 补丁特性

- **纯原生横版排版**：从左至右行进、从上至下换行，完美契合剧本默认的全屏 NVL 文本区域（`40, 30, 760, 560`）。
- **标点符号完全校正**：彻底修复引号（`「` `」` `“` `”`）、括号、破折号的 90 度旋转畸变，句号/逗号/顿号精准落在文本基线上。
- **原版文件零破坏**：生成独立的 `tosui_cn_horizontal.exe`，原版 `tosui_cn.exe` 完好保留，想看竖版依然可随时切换。
- **即开即用**：零额外依赖，无需配置复杂环境或注入外部 DLL。

## 🚀 快速使用方法

### 方法一：使用 Python 脚本生成（推荐）

1. 下载本仓库中的 `patch.py`。
2. 将 `patch.py` 复制到《灯穂奇譚》游戏根目录（即含有 `tosui_cn.exe` 的文件夹）。
3. 运行脚本：
   ```bash
   python patch.py
   ```
4. 运行完成后，游戏目录下会生成 **`tosui_cn_horizontal.exe`**。
5. 双击 **`tosui_cn_horizontal.exe`** 即可开始游戏！

## 🛠️ 逆向工程与技术原理

《灯穂奇譚》采用水鏡社独占定制的 **AOD 引擎**（Win32 DirectDraw + GDI 字形光栅化）。

经过逆向分析，引擎内部实际保留了完整的横向排版分支逻辑（`Mode = 0`），但默认硬编码为纵书（`Mode = 1`）：

1. **起始坐标修正 (`0x00435906`)**：
   - 旁路竖排右侧边距起始逻辑，强制采用左上角 `(X0, Y0)` 作为段落起始。
2. **排版双模流水线激活 (`0x00436840 ~ 0x00437400`)**：
   - 将排版例程、块格式化与步进宽度累加分支强制重定向至横向流（`X += char_width`，换行 `Y += line_height, X = X0`）。
3. **字形光栅化矩阵重置 (`0x0043809F ~ 0x0043838D`)**：
   - 禁用 `GetGlyphOutlineA` 在竖排模式下注入的 90 度旋转变换矩阵（`0x9f4e88`），恢复为标准单位矩阵（`0x9f4e78`）。
   - 旁路 `0x00438272` 处的竖排标点右上角错位偏移量分支。
