# 《灯穂奇譚》简体中文汉化版 - 横版文字补丁

本项目是针对视觉小说《灯穂奇譚》（水鏡社 AOD 引擎）简体中文汉化版的**横版文字排版补丁**。

---

## 📥 下载与使用

1. 前往 **[Releases 页面](https://github.com/turboegg1145/tousui-kitan-horizontal-patch/releases)** 下载预编译好的 **`tosui_cn_horizontal.exe`**。
2. 将其放入《灯穂奇譚》游戏根目录（与 `tosui_cn.exe` 处于同一文件夹）。
3. 运行 **`tosui_cn_horizontal.exe`** 即可进入横版阅读模式。

原版 `tosui_cn.exe` 不受影响，随时可运行原版切换回竖排。

---

## 📝 补丁说明

- **横版排版**：从左至右行进、从上至下换行，排版适配默认全屏 NVL 显示区域（`40, 30, 760, 560`）。
- **标点校正**：修复引号（`「` `」` `“` `”`）、括号、破折号在横排下的 90 度旋转畸变，句号与逗号正常基线对齐。
- **无侵入**：生成独立可执行文件，无需配置额外环境。

---

## 🛠️ 本地构建 / 源码使用

如需通过源码生成补丁：

```bash
python patch.py [path/to/tosui_cn.exe] [path/to/tosui_cn_horizontal.exe]
```

## 🔬 逆向工程与实现细节

AOD 引擎内部保留了横向与纵向双模排版代码：

1. **段落起始坐标 (`0x00435906`)**：强制指定左上起始边距 `(X0, Y0)`。
2. **排版流水线重定向 (`0x00436840 ~ 0x00437400`)**：强制切换至横向推进分支（单字 `X += char_width`，换行 `Y += line_height, X = X0`）。
3. **光栅化矩阵重置 (`0x0043809F ~ 0x0043838D`)**：将 `GetGlyphOutlineA` 的变换矩阵强制恢复为单位矩阵（`0x9f4e78`），并旁路竖排标点偏移分支（`0x00438272`）。
